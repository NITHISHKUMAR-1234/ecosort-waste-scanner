# EcoSort – AI-Powered Waste Identification and Classification

## Overview
EcoSort is an AI-powered, camera-based waste identification system designed to help users identify and classify waste. It analyses an uploaded image or camera-captured image and identifies the object as biodegradable or non-biodegradable.

## Features
- Camera-based waste image capture
- Image upload and AI-powered object identification
- Biodegradable and non-biodegradable classification
- Confidence score for predictions
- 5R sustainability guidance
- Disposal tips to encourage responsible waste management

## How It Works
1. Open the EcoSort application.
2. Capture an image using the camera or upload an image.
3. Let the AI analyse the selected image.
4. View the identified object and its waste category.
5. Follow the suggested sustainability and disposal guidance.
